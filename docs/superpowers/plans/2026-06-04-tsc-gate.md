## Task 2: Fix the 8 real type errors (make `check` GREEN)

**Files:**

> All six edits below were applied together and verified to bring `bun run check` to **0 errors**. Run `bun run check` after each edit to watch the count drop; do not add `// @ts-ignore`/`as any` — these are real source fixes.

- [ ] **Step 1: `runtime/notification.ts` — cast the union handler inside the body (errors 4–5)**

The bug: `on()`'s `handler` param is a *union of two function types*; calling it forces args to the *intersection* `string & NotificationResponse`. (Overload signatures can't be used here — `Notification` is an object literal, which rejects bodiless overloads.) Fix: narrow `handler` to the right shape per branch with a local cast, and drop the now-redundant `as NotificationResponse` casts.

Replace the whole `on(...)` method body:
```ts
  on(event: "click" | "action" | "response", handler: ((response: NotificationResponse) => void) | ((notificationId: string, actionId?: string) => void)): () => void {
    if (event === "response") {
      // Unified handler — fires for both clicks and actions
      const offClick = Events.on("__notif:click", (payload: any) => {
        const data = typeof payload === "string" ? JSON.parse(payload) : payload;
        handler({ id: data.id, actionId: "DEFAULT" } as NotificationResponse);
      });
      const offAction = Events.on("__notif:action", (payload: any) => {
        const data = typeof payload === "string" ? JSON.parse(payload) : payload;
        handler({
          id: data.id,
          actionId: data.action,
          userText: data.userText,
        } as NotificationResponse);
      });
      return () => { offClick(); offAction(); };
    }

    // Legacy click/action handlers
    const eventName = event === "click" ? "__notif:click" : "__notif:action";
    return Events.on(eventName, (payload: any) => {
      const data = typeof payload === "string" ? JSON.parse(payload) : payload;
      handler(data.id, data.action);
    });
  },
```
with:
```ts
  on(event: "click" | "action" | "response", handler: ((response: NotificationResponse) => void) | ((notificationId: string, actionId?: string) => void)): () => void {
    if (event === "response") {
      // Unified handler — fires for both clicks and actions
      const responseHandler = handler as (response: NotificationResponse) => void;
      const offClick = Events.on("__notif:click", (payload: any) => {
        const data = typeof payload === "string" ? JSON.parse(payload) : payload;
        responseHandler({ id: data.id, actionId: "DEFAULT" });
      });
      const offAction = Events.on("__notif:action", (payload: any) => {
        const data = typeof payload === "string" ? JSON.parse(payload) : payload;
        responseHandler({
          id: data.id,
          actionId: data.action,
          userText: data.userText,
        });
      });
      return () => { offClick(); offAction(); };
    }

    // Legacy click/action handlers
    const legacyHandler = handler as (notificationId: string, actionId?: string) => void;
    const eventName = event === "click" ? "__notif:click" : "__notif:action";
    return Events.on(eventName, (payload: any) => {
      const data = typeof payload === "string" ? JSON.parse(payload) : payload;
      legacyHandler(data.id, data.action);
    });
  },
```

- [ ] **Step 2: `bootstrap/webview.ts` — tighten `_syncPending.resolve` (error 1)**

The promise resolves `"notified" | "timed-out"`, but the field types `resolve` as `(v: string) => void`. Replace:
```ts
    _syncPending: {} as Record<string, { resolve: (v: string) => void; timer?: ReturnType<typeof setTimeout> }>,
```
with:
```ts
    _syncPending: {} as Record<string, { resolve: (v: "notified" | "timed-out") => void; timer?: ReturnType<typeof setTimeout> }>,
```

- [ ] **Step 3: `runtime/worker-globals/crypto.ts` — assert the digest buffer type (error 8)**

`out.buffer.slice(...)` is `ArrayBuffer | SharedArrayBuffer`; the function returns `ArrayBuffer`. A `Uint8Array` from `createHash().digest()` always has an `ArrayBuffer` backing. Replace:
```ts
        return out.buffer.slice(out.byteOffset, out.byteOffset + out.byteLength);
```
with:
```ts
        return out.buffer.slice(out.byteOffset, out.byteOffset + out.byteLength) as ArrayBuffer;
```

- [ ] **Step 4: `cli/src/native.ts` — hoist the narrowed `ext` into the closure (error 3)**

`ext` is `".m" | ".c" | null`; the `if (!ext) return []` guard narrows it in the outer scope, but the narrowing doesn't reach the nested `walk` closure, so `entry.name.endsWith(ext)` sees `string | null`. Fix: capture the narrowed value in a `const` the closure can use.

Replace:
```ts
  if (!ext) return [];

  const results: string[] = [];
  async function walk(dir: string): Promise<void> {
```
with:
```ts
  if (!ext) return [];
  const fileExt: string = ext;

  const results: string[] = [];
  async function walk(dir: string): Promise<void> {
```
and replace (in the same function):
```ts
      } else if (entry.isFile() && entry.name.endsWith(ext)) {
```
with:
```ts
      } else if (entry.isFile() && entry.name.endsWith(fileExt)) {
```

- [ ] **Step 5: `cli/src/downlevel-bare-js.ts` — make the `@babel/core` specifier non-literal (error 2)**

`@babel/core` ships no declaration file (TS7016). The neighboring line 68 already dodges resolution with `as string`. Match it. Replace:
```ts
  const babel = await import("@babel/core");
```
with:
```ts
  const babel = await import("@babel/core" as string);
```

- [ ] **Step 6: `runtime/worker-globals.ts` — drop the two ambient globals that clash with lib.dom (errors 6–7)**

The ambient `var onmessage` and `var self` redeclare globals that `lib.dom` already defines (TS2403). Consumers either use `(self as any)` casts (`bootstrap/worker.ts`) or `globalThis.onmessage` (`bootstrap/bare-worker.ts`) — both compile against the lib.dom definitions. (Verified: removing these introduces no new errors anywhere in scope.)

Remove this block (the comment + the `var onmessage` line):
```ts
  /** Raw message handler — receives all messages from the WebView. */
  var onmessage: ((event: { data: unknown }) => void) | null;

  /** The native bridge — host objects for direct C calls. */
```
→ leaving just:
```ts
  /** The native bridge — host objects for direct C calls. */
```

And remove the `var self` line so:
```ts
    /** Sync notify — wake waiters on a key. */
    syncNotify(key: string, count?: number): void;
  };

  var self: typeof globalThis;
}
```
becomes:
```ts
    /** Sync notify — wake waiters on a key. */
    syncNotify(key: string, count?: number): void;
  };
}
```
